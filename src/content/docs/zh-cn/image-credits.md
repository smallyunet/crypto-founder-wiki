## 使用原则

- 图片只用于人物和网络识别，不表示作者、摄影者或相关机构认可本站。
- 不把搜索引擎缩略图或新闻网站图片当作可自由转载素材。
- 页面提供描述性替代文本、固定宽高和许可链接。
- 如果权利人认为归属或许可记录有误，可通过 GitHub issue 提出更正或移除请求。
