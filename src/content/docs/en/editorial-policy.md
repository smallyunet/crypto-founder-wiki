The project prioritizes primary records, clear attribution, visible uncertainty, and corrections backed by evidence. It does not publish home addresses, private contact details, identity documents, details about minors, or sensitive family information unrelated to a legitimate public-interest inquiry.

## Sensitive event names

When a highly sensitive political event is relevant to a person's history, the dossier should preserve the necessary facts and sources while partially masking the event name—for example, `June F*****`. The rule applies to headings, body text, tables, image alternative text, and metadata in every language. Build validation blocks common unmasked forms from publication.
